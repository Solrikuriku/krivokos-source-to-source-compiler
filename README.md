Очередная курсовая работа. Выполнена в 2023 году.</br>
Представляет собой транслятор (или компилятор source-to-source) для собственного языка 
программирования "Кривокос" с переводом на рабочий C++ код.

Стек: Visual Studio, C#, .NET Framework.
Осторожно, легаси! Код больше не поддерживался с момента сдачи.

По заданию, язык программирования обязан был в себе содержать:
- наличие целого, вещественного и строкового типа данных
- ввод переменной с клавиатуры
- вывод переменной на экран
- цикл с предусловием
- возможность создавать и вызывать функции
- условный оператор
- аналог директивы #include из C++

Для собственного языка программирования были разработаны:
- лексический анализатор
- синтаксический анализатор
- семантический анализатор
